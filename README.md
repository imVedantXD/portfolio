🔐 Environment Variables

Some application features may require environment variables.

Never commit private API keys, passwords, tokens, or other secrets to GitHub.

Use environment variables for sensitive configuration and keep local secret files such as ".env" outside version control.

A safe example can be documented later as:

.env.example

without containing real credentials.
